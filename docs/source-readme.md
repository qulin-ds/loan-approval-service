# Сервис прогнозирования одобрения кредита

Самостоятельный учебный проект. **Автор — Артём Мастеров.**

## Возможности

- Обучение моделей машинного обучения для прогноза одобрения кредита.
- Предобработка данных и сохранение модели с пайплайном.
- FastAPI для загрузки модели и получения предсказаний.
- Обработка отдельных записей и CSV-файлов.
- Веб-интерфейс на HTML, CSS и JavaScript.
- Оценка качества по ROC-AUC при наличии целевой переменной.

## Структура

- `backend/api/` — API и схемы данных.
- `backend/ml/` — обучение и оценка моделей.
- `backend/core/` — работа с моделью и предобработка.
- `backend/tests/` — тесты API.
- `frontend/` — веб-интерфейс.
- `.sourcecraft/` — конфигурация CI исходного размещения.

## Запуск

```sh
cd backend
uv sync
uv run python ml/train.py
uv run uvicorn api.main:app --reload
```

Приложение: http://127.0.0.1:8000. Дополнительные сведения — в [основном README](../README.md) и [описании backend](../backend/README.md).
